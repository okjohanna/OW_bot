## OW_bot

### Summary
___

The modern gamer can no longer afford to waste valuable keystrokes on repetitive, low-value communication tasks. Every second spent typing *"@everyone is anyone down for Overwatch?"* is a second not spent sitting in queue, staring at a 6-minute wait time.

OW_bot is a next-generation, AI-adjacent, Rust-powered Discord integration solution that streamlines your Overwatch session initialization pipeline by up to 97%*.

### Key Features
___
- Frictionless Overwatch session facilitation: `/ow` pings everyone. That's it. That's the feature.
- Blazingly fast: Written in Rust.
- Scalable: Works whether your server has 3 members or 3000 members.
